Para Pasajeros

Visualiza buses en mapa real, conoce si están llenos o averiados, solicita paradas para subir (marcador azul) o bajar (marcador rojo) y recibe alertas sonoras a 50 metros.

🚌

Para Conductores

Monitorea tu ruta, pasajeros que esperan subir o bajar con marcadores diferenciados, marca tu bus como LLENO o AVERIADO y recibe avisos sonoros de proximidad a 50m.

🏢

Para Empresas y Admin

Gestiona flotillas, rutas con waypoints geográficos, paradas programadas, asignación de conductores, reportes de averías y horarios de circulación.
